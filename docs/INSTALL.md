# Notebook — установка и обновление

## Две сборки

| | Release | Debug |
|---|---|---|
| Для чего | Ежедневное использование | Разработка и проверка изменений |
| Название на телефоне | Notebook | Notebook Debug |
| Идентификатор | `com.example.notebook` | `com.example.notebook.debug` |
| Подпись | Ваш ключ `keystore/notebook-release.jks` | Отладочный ключ Android Studio |
| Где файл | `app/build/outputs/apk/release/app-release.apk` | `app/build/outputs/apk/debug/app-debug.apk` |

Это два разных приложения с разными заметками. Debug можно ставить и удалять как угодно, release-заметки он не трогает.

## Ключ подписи — сделайте резервную копию

Файлы `keystore/notebook-release.jks` и `keystore.properties` (пароль) лежат в папке проекта, но **не попадают в git**. Скопируйте оба в надёжное место вне компьютера (например, в менеджер паролей или на флешку).

Без них нельзя выпустить обновление, которое встанет поверх установленного приложения: Android требует ту же подпись. Новый ключ = удалить приложение = потерять заметки (если нет экспорта).

## Первый переход с debug на release (один раз)

До этапа 7 на телефоне стояла debug-сборка с идентификатором `com.example.notebook`. Release подписан другим ключом, поэтому поверх неё не встанет. Перенос заметок:

1. Откройте Notebook на телефоне → Настройки → **Экспорт заметок** → сохраните файл (например, в «Загрузки»).
2. Убедитесь, что файл есть: Файлы → Загрузки → `notebook-backup-ГГГГ-ММ-ДД.json`.
3. Удалите приложение Notebook (долгое нажатие на иконку → «Удалить»).
4. Установите release (см. ниже).
5. Откройте Notebook → Настройки → **Импорт заметок** → выберите файл. Появится итог «Добавлено N, обновлено 0, пропущено 0».

## Установка и обновление release

С компьютера, телефон подключён к Android Studio по Wi-Fi или кабелю:

```bash
./gradlew assembleRelease
```

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

`-r` = обновить, сохранив данные. Пока ключ тот же, обновление всегда встаёт поверх и заметки остаются.

Без компьютера: скопируйте `app-release.apk` на телефон и откройте его в «Файлах» (Android попросит разрешить установку из этого источника).

Перед каждым обновлением поднимайте `versionCode` в `app/build.gradle.kts` (1 → 2 → 3…) и при желании `versionName` («1.1»). Android не даёт ставить версию с меньшим `versionCode`.

## Резервные копии

- **Автоматически:** Android Auto Backup сохраняет базу заметок и настройки в резервную копию Google аккаунта телефона (если она включена в настройках телефона). При переустановке на том же аккаунте данные возвращаются.
- **Вручную:** Настройки → Экспорт заметок. Файл JSON можно хранить где угодно; импорт ничего не удаляет и не создаёт дубликатов.
