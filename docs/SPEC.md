# Notebook — спецификация внешнего вида и функционала

21 нояб. 2026 г.

## Назначение и принципы

Этот документ задаёт, как Notebook выглядит и что умеет в первой версии. Код пишется по нему. Если поведение здесь не описано, оно не входит в v1.

Принципы, по которым решаются спорные вопросы:

1. **Заметка важнее интерфейса.** Текст занимает максимум места, служебные элементы прячутся, пока не нужны.
2. **Ничего не теряется.** Автосохранение без кнопки «Сохранить», удаление с возможностью отмены, корзина вместо мгновенного стирания.
3. **Нативно для Android.** Стандартные компоненты Material 3, системные жесты, системная кнопка «Назад», динамические цвета Pixel. Никаких самодельных аналогов того, что уже есть в системе.
4. **Одна рука.** Частые действия — в нижней половине экрана, под большим пальцем.
5. **Сдержанность.** Анимации короткие и функциональные, без декоративных эффектов.

## Визуальный стиль

Стиль — Material 3 (Material You) с динамическими цветами обоев Pixel по умолчанию. Все цвета, шрифты и формы берутся из MaterialTheme, а не задаются в экранах вручную.

| Элемент | Решение |
|---|---|
| Цветовая схема | Dynamic color (dynamicLightColorScheme / dynamicDarkColorScheme); запасная схема — собственная, с сине-зелёным акцентом |
| Тема | Светлая / Тёмная / Как в системе (по умолчанию — как в системе) |
| Шрифт | Системный (Google Sans / Roboto на Pixel), стандартная шкала M3; отдельные шрифты не подключаем |
| Заголовок в списке | titleMedium, до 2 строк |
| Текст в списке | bodyMedium, до 6 строк в сетке и до 3 в списке, далее многоточие |
| Заголовок в редакторе | headlineSmall |
| Текст в редакторе | bodyLarge; размер меняется в настройках: маленький / средний / крупный |
| Даты и метки | labelSmall, цвет onSurfaceVariant |
| Карточка заметки | Скругление 16 dp, без тени; у заметки без цвета — тонкая рамка outlineVariant |
| Отступы | Сетка кратна 4 dp: края экрана 16 dp, между карточками 8 dp, внутри карточки 12–16 dp |
| Иконки | Material Symbols (Rounded), только нужные из material-icons-extended |
| Иконка приложения | Adaptive icon + монохромная версия для тематических иконок Android |
| Edge-to-edge | Включён: контент идёт под статус-бар и навигационную полоску, инсеты учитываются |

### Цвета заметок

У заметки один из 9 цветов. В базе хранится имя цвета (`NoteColor.SAGE`), а не HEX. Поэтому один и тот же цвет рисуется по-разному в светлой и тёмной теме, и палитру можно подправить без миграции базы.

| Имя в коде | Название | Светлая тема | Тёмная тема |
|---|---|---|---|
| DEFAULT | Без цвета | surfaceContainerLow + рамка | surfaceContainerLow + рамка |
| CORAL | Коралловый | #FAAFA8 | #77172E |
| PEACH | Персиковый | #F39F76 | #692B17 |
| SAND | Песочный | #FFF8B8 | #7C4A03 |
| MINT | Мятный | #E2F6D3 | #264D3B |
| SAGE | Шалфей | #B4DDD3 | #0C625D |
| FOG | Туманный | #D4E4ED | #256377 |
| STORM | Грозовой | #AECCDC | #284255 |
| DUSK | Сиреневый | #D3BFDB | #472E5B |

Правила:
- Цвет применяется к карточке в списке и к фону редактора целиком, включая верхнюю панель.
- Текст на цветном фоне должен иметь контраст не ниже 4.5:1 (WCAG AA). В светлой теме текст тёмный, в тёмной — светлый.
- Выбор цвета — ряд кружков 48 dp в нижней панели (bottom sheet) редактора; текущий отмечен галочкой.
- HEX-значения выше — стартовые, подбираются на живом экране Pixel 8.

## Экраны

В приложении шесть экранов в одной Activity. Навигация — Navigation Compose, кнопка и жест «Назад» работают везде.

| Экран | Как попасть | Назначение |
|---|---|---|
| Главный | Запуск приложения | Список или сетка заметок |
| Редактор | FAB, нажатие на заметку | Создание и редактирование |
| Поиск | Строка поиска на главном | Поиск по заголовку и тексту |
| Категории | Боковое меню → «Управление категориями» | Создание, переименование, удаление |
| Архив и Корзина | Боковое меню | Просмотр и восстановление |
| Настройки | Боковое меню | Тема, вид списка, экспорт и импорт |

### Главный экран
- Верх: строка поиска в форме «пилюли» (M3 SearchBar). Слева в ней иконка меню, справа — переключатель «список / сетка».
- Фильтр категорий: горизонтальный ряд чипов под поиском: «Все» и категории пользователя. Прокручивается вбок.
- Сортировка: кнопка в конце ряда чипов, открывает меню с вариантами порядка.
- Список: секция «Закреплённые» сверху, ниже «Другие». Заголовки секций показываются, только если есть хотя бы одна закреплённая заметка.
- Сетка: 2 колонки, карточки разной высоты (staggered grid). Список — 1 колонка.
- Карточка: заголовок, начало текста, чип категории, дата изменения («14:05» сегодня, «вчера», «12 ноя», «12 ноя 2025» для прошлых лет), иконка булавки у закреплённых.
- FAB: Extended FAB «Заметка» справа внизу. При прокрутке вниз сжимается до круглой кнопки «+».
- Пустое состояние: иконка и текст «Заметок пока нет. Нажмите «+», чтобы создать». Для пустого фильтра — «В этой категории нет заметок».
- Выбор нескольких: долгое нажатие включает режим выбора. Верхняя панель показывает счётчик и действия: закрепить, цвет, категория, архив, удалить.

### Редактор
- Верхняя панель: «Назад», справа — закрепить, архив и меню «⋮» (удалить, копировать, поделиться).
- Поля: заголовок (плейсхолдер «Заголовок») и текст («Заметка»), без рамок — как лист бумаги. Текст прокручивается вместе с экраном.
- Нижняя панель: кнопки «Цвет» и «Категория» слева, справа — «Изменено 14:05». Панель поднимается над клавиатурой.
- Даты: создание и изменение целиком — в меню «⋮» → «Информация».
- Новая заметка: курсор сразу в тексте, клавиатура открыта. Существующая — открывается для чтения, клавиатура по нажатию на текст.

### Поиск
- Раскрывается из строки на главном на весь экран (стандартное поведение M3 SearchBar).
- Результаты обновляются по мере ввода с задержкой ~300 мс. Совпадения подсвечиваются.
- Нет результатов — «Ничего не найдено».

### Боковое меню
Modal Navigation Drawer: «Заметки», список категорий со счётчиками, «Управление категориями», «Архив», «Корзина», «Настройки».

### Архив и Корзина
- Такая же сетка, как на главном, без FAB.
- В Корзине: плашка «Заметки удаляются навсегда через 30 дней», кнопка «Очистить» с подтверждением. Заметка из корзины открывается только для чтения, с кнопкой «Восстановить».

### Настройки

| Настройка | Варианты | По умолчанию |
|---|---|---|
| Тема | Светлая, Тёмная, Как в системе | Как в системе |
| Динамические цвета | Вкл / Выкл | Вкл |
| Вид списка | Сетка, Список | Сетка |
| Сортировка | По изменению, По созданию (новые / старые сверху) | По изменению, новые сверху |
| Размер текста в редакторе | Маленький, Средний, Крупный | Средний |
| Экспорт заметок | Кнопка → системный диалог сохранения файла | — |
| Импорт заметок | Кнопка → выбор файла | — |
| О приложении | Версия | — |

## Функционал и правила поведения

Здесь собраны правила, которые проверяются тестами. Каждое правило — одно ожидаемое поведение.

### Создание и автосохранение
- Запись в базу создаётся при первом введённом символе, а не при нажатии FAB.
- Изменения сохраняются через ~500 мс после остановки ввода (debounce).
- Кроме того, сохранение принудительно срабатывает при выходе из редактора, сворачивании приложения и повороте экрана.
- Если новая заметка пустая (заголовок и текст пусты или из пробелов) при выходе, она не сохраняется. Появляется снекбар «Пустая заметка удалена».
- Дата изменения обновляется только при реальном изменении заголовка, текста, цвета или категории. Открытие, закрепление и архивация дату не меняют.
- В редакторе работает «Отменить / Повторить» в пределах текущего открытия. Кандидат на v1.1, если усложнит v1.

### Удаление, архив, корзина
- «Удалить» переносит заметку в корзину (поле deletedAt) и показывает снекбар «Заметка в корзине · Отменить».
- «В архив» скрывает заметку с главного экрана, тоже со снекбаром «Отменить». Закрепление при этом снимается.
- Заметки старше 30 дней в корзине удаляются навсегда при запуске приложения. WorkManager для этого не нужен.
- Окончательное удаление и «Очистить корзину» — только после диалога подтверждения.
- Архивные и удалённые заметки не попадают в поиск на главном.

### Закрепление
- Закреплённые всегда в верхней секции, внутри неё действует та же сортировка, что и для остальных.
- Закрепить / открепить можно из редактора и из режима выбора.

### Сортировка и поиск
- Четыре варианта: по дате изменения или создания, в каждом — новые или старые сверху. Выбор запоминается в DataStore.
- Поиск не зависит от регистра и ищет подстроку в заголовке и тексте («моло» находит «Молоко»).
- Заметки с совпадением в заголовке идут первыми.
- В v1 поиск делается через LIKE. Для нескольких тысяч заметок этого хватает; FTS — если понадобится.

### Категории
- У заметки ноль или одна категория. Это проще тегов и покрывает фильтрацию из требований.
- Название категории уникально (без учёта регистра), до 30 символов.
- Удаление категории не удаляет заметки: они остаются без категории. Диалог сообщает, сколько заметок затронет.
- В редакторе категорию можно создать прямо из списка выбора («+ Новая категория»).

## Анимации, жесты и эргономика

Анимации длятся 200–300 мс и используют стандартные кривые M3. Если в системе выключены анимации, приложение это уважает.

| Момент | Анимация |
|---|---|
| Открытие заметки | Карточка плавно раскрывается в редактор (shared element). Запасной вариант — fade + сдвиг |
| Появление и исчезновение заметок в списке | animateItem() — соседние карточки плавно сдвигаются |
| Закрепление | Карточка переезжает в верхнюю секцию |
| Смена цвета | Плавный переход фона (animateColorAsState) |
| FAB | Сжатие и расширение при прокрутке |
| Смена темы | Без мерцания, цвета перетекают |

Жесты:
- Долгое нажатие — режим выбора, с лёгкой вибрацией (haptic).
- Системный жест «Назад» с предпросмотром (predictive back) включён.

Эргономика на Pixel 8:
- Экран 6.2″, 1080×2400, плотность ~2.6x — примерно 412×915 dp. Макеты рассчитываются на ширину 412 dp.
- Минимальная зона нажатия — 48×48 dp.
- FAB, панель цвета и категории, панели выбора — внизу экрана. Вверху — только то, что нужно редко.
- Edge-to-edge: отступы под вырез камеры, статус-бар и полоску жестов берутся из WindowInsets. Последняя карточка списка не прячется под FAB.
- Клавиатура: imePadding(), курсор всегда виден над клавиатурой. В заголовке клавиша «Далее» переводит в текст. Автозаглавная буква в начале предложения.
- Ориентация — портретная. При этом состояние переживает пересоздание Activity (смена темы, шрифта, языка).
- При крупном системном шрифте (200%) интерфейс не ломается. У иконок есть contentDescription для TalkBack.

## Модель данных и экспорт

Две таблицы Room: notes и categories. Все даты хранятся как миллисекунды UTC (Long), в локальное время переводятся только при показе.

### Таблица notes

| Поле | Тип | Примечание |
|---|---|---|
| id | Long, PK, autoGenerate | |
| uuid | String, уникальный | Нужен, чтобы импорт не создавал дубликаты |
| title | String | Может быть пустым |
| content | String | Обычный текст, без форматирования |
| color | String | Имя из NoteColor, по умолчанию DEFAULT |
| categoryId | Long? | FK → categories.id, ON DELETE SET NULL, индекс |
| isPinned | Boolean | |
| isArchived | Boolean | |
| deletedAt | Long? | null = не в корзине |
| createdAt | Long | |
| updatedAt | Long | |

Таблица categories: id (Long, PK), name (String, уникальный индекс без учёта регистра), createdAt (Long).

Надёжность:
- Версия базы начинается с 1, exportSchema = true, JSON-схемы лежат в репозитории.
- Каждое изменение схемы — с миграцией и тестом миграции. fallbackToDestructiveMigration запрещён.
- В манифесте включён системный Auto Backup Android для файла базы. Дополнительной сети и аккаунтов это не требует.

Экспорт и импорт (JSON):
- Экспорт через системный диалог сохранения (Storage Access Framework, CreateDocument). Имя файла по умолчанию — notebook-backup-2026-11-21.json. Разрешения на доступ к хранилищу не нужны.
- В файл попадают все заметки, включая архив и корзину, и все категории.
- Формат: `{"formatVersion": 1, "exportedAt": …, "categories": […], "notes": […]}`. Категория у заметки указывается по имени, а не по id.
- Импорт добавляет данные и ничего не удаляет. Заметка с уже существующим uuid обновляется, только если в файле её updatedAt новее.
- Импорт выполняется одной транзакцией. Битый файл не меняет базу и показывает понятную ошибку.
- После импорта — итог: «Добавлено 12, обновлено 3, пропущено 40».
- Сериализация — kotlinx.serialization.

## Этапы и критерии приёмки

v1 собирается за семь этапов. Каждый заканчивается сборкой debug APK и проверкой на Pixel 8.

1. **Каркас.** Gradle (Kotlin DSL, version catalog), тема M3 с динамическими цветами, edge-to-edge, навигация с заглушками экранов.
2. **Данные.** Room (notes, categories), DAO, репозиторий, ручной DI-контейнер, unit-тесты DAO.
3. **Список и редактор.** Создание, редактирование, автосохранение, удаление в корзину с отменой, закрепление, цвета.
4. **Поиск и сортировка.**
5. **Категории.** Управление, фильтр чипами, боковое меню.
6. **Архив, корзина, настройки.** DataStore, переключение темы, автоочистка корзины.
7. **Экспорт и импорт, полировка.** JSON, анимации, иконка, release APK с подписью.

Не входит в v1: форматирование текста, чек-листы, картинки, напоминания, виджет на рабочий стол, пароль, синхронизация, несколько категорий на заметку.

v1 готова, когда на Pixel 8 проверено:
- [ ] Заметка создаётся, редактируется и переживает перезапуск приложения и телефона.
- [ ] Текст не теряется, если свернуть приложение сразу после ввода или выгрузить его из недавних.
- [ ] Удаление, отмена, восстановление из корзины и окончательное удаление работают.
- [ ] Поиск находит по заголовку и тексту, в том числе кириллицу в другом регистре.
- [ ] Закрепление, цвета, категории и фильтр работают и сохраняются.
- [ ] Светлая и тёмная темы читаемы на всех экранах и во всех цветах заметок.
- [ ] Экспорт → очистка данных приложения → импорт возвращает всё без потерь. Повторный импорт не создаёт дубликатов.
- [ ] Обновление APK поверх старой версии сохраняет заметки.
- [ ] Прокрутка 500 заметок идёт без рывков. Холодный старт — меньше 1 секунды в release-сборке.
