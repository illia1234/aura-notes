# Редизайн «Aura» — согласованные решения

21 нояб. 2026 г. Основа — описание дизайна от пользователя (тёмная тема, «мягкое стекло», неоновые акценты) плюс ответы на опрос. Где этот документ расходится с `SPEC.md`, действует этот документ. Функции и правила поведения из `SPEC.md` (автосохранение, корзина, поиск, импорт и т. д.) не меняются.

## Решения из опроса

| Вопрос | Решение |
|---|---|
| Тема | Только тёмная. Настройки «Тема» и «Динамические цвета» убираются. |
| Название | Приложение называется **Aura**. Новая иконка — геометрическая буква «А». `applicationId` не меняется, данные сохраняются. |
| Навигация | Нижняя панель из 5 вкладок вместо бокового меню. |
| Метки | Одна метка на заметку (это текущая категория), показывается «таблеткой» `#работа`. База не меняется. |
| Вкладка «Сердце» | Закреплённые заметки. Закрепление в интерфейсе = «сердечко». База не меняется. |
| Цвет | Цвет заметки (текущие 9 цветов) показывается светящимся кружком слева на карточке, а не заливкой. |
| Список | Только список: карточки на всю ширину — кружок, заголовок, 1 строка текста, дата, метка. Сетки нет. |
| Шрифт | Inter (встроенный, с кириллицей). |
| Архив и Корзина | Во вкладке «Метки» (папки): список меток со счётчиками, ниже «Архив» и «Корзина». |
| Открытие заметки | Настоящий shared element: карточка раскрывается в редактор, остальное гаснет; «Назад» — обратно. |
| Редактор | Тёмный фон, цвет заметки — мягкое свечение сверху и кружок у заголовка. |

## Визуальный стиль

- **Фон:** #121212.
- **Карточки («стекло»):** полупрозрачная тёмная панель (≈ #2C2C2C, частичная прозрачность), лёгкий градиент, тонкий светлый контур-блик, крупное скругление.
- **Текст:** основной #FFFFFF, второстепенный (даты, метки) #A0A0A0.
- **Акценты (неон, приглушённые):** мята, персик, небо, лаванда, лимон + остальные цвета палитры заметок в той же гамме.
- **Иконки:** контурные (outline), белые / светло-серые.
- **Заголовок экрана** («Заметки»): крупный, тонкий (Light).
- **Заголовок карточки:** Medium. **Метаданные:** Regular, мелко.

## Экраны и элементы

1. **Верхняя панель:** слева логотип «А», по центру «Aura», справа лупа (открывает поиск).
2. **Главная (Домик):** крупный заголовок «Заметки», под ним чипы меток для фильтра и сортировка, список стеклянных карточек. При прокрутке верх списка мягко гаснет.
3. **FAB:** круглая кнопка «+» с сине-фиолетовым градиентом и неоновым свечением, справа внизу над нижней панелью.
4. **Нижняя панель:** Домик (Главная), Бирка (Метки / папки), Лупа (Поиск), Сердце (Закреплённые), Шестерёнка (Настройки). Контурные иконки, активная — белая со свечением и точкой-индикатором сверху. Фон — как основной, с эффектом матового стекла.
5. **Поиск:** отдельная вкладка с полем поиска и результатами (правила поиска прежние).
6. **Метки:** метки со счётчиками (нажатие — главная с фильтром), управление метками (создать, переименовать, удалить), «Архив», «Корзина».
7. **Настройки:** сортировка, размер текста, экспорт/импорт, версия.

## Анимации и отклик

- Нажатия — мягкая пружинистая анимация (лёгкое сжатие карточки и кнопок).
- Открытие заметки — раскрытие карточки на весь экран (shared element), «Назад» сворачивает обратно, в том числе жестом с предпросмотром.
- Переключение вкладок — плавная смена цвета иконки и движение точки-индикатора.
- Инерционная плавная прокрутка (стандартная в Compose).
- Если в системе отключены анимации, приложение это соблюдает.

## Технические ограничения (решено по умолчанию)

- **Размытие фона под стеклом (backdrop blur)** в Compose без сторонних библиотек недоступно: `Modifier.blur` размывает сам элемент, а не то, что под ним. Стекло имитируется полупрозрачностью, градиентом и бликом по контуру; на тёмном однотонном фоне разница почти не видна. Для нижней панели — то же самое. Если захочется настоящего размытия, можно добавить библиотеку Haze (отдельное решение).
- Inter встраивается как ресурс шрифта (≈300 КБ, лицензия SIL OFL — свободная).
- Схема базы данных не меняется — миграция не нужна, экспорт/импорт совместимы.
