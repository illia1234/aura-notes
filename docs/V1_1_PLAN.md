# Aura v1.1 — план

22 нояб. 2026 г. Основа — запрос пользователя (макет «Calendar» на экране Aura) и ответы на опрос. Где расходится с `SPEC.md` и `REDESIGN_AURA.md`, действует этот документ.

## Решения из опроса

| Вопрос | Решение |
|---|---|
| Вкладка «Сердце» | Заменяется вкладкой **Календарь**. |
| Избранное | **Убирается полностью**: нет сердечек, нет секции «Избранные». Метки остаются. Поле `isPinned` в базе и в экспорте сохраняется (для совместимости), но приложение его больше не показывает и не учитывает при сортировке. |
| Цвета дней | **График по шаблону**: зелёный = рабочий день (смена), красный = выходной. Без настроенного графика дни нейтральные (тёмно-серые). |
| Шаблоны | Готовые **2/2**, **5/2** (Пн–Пт работа, Сб–Вс выходные), **сутки через трое (1/3)** и **свой N/M**. Для циклических — дата начала графика. |
| Исключения | Долгое нажатие на день переключает **смена ↔ выходной** поверх графика; повторное — «как в графике». |
| Заметка смены | Обычная заметка с датой. Кнопка «+ Заметка смены» создаёт заметку на выбранный день. Под календарём — заметки выбранного дня. |
| Дата у заметки | **Любой** заметке можно дать дату или убрать её: кнопка «Дата» в нижней панели редактора. |
| Язык | Настройка «Язык»: **Как в системе / Русский / English**. Также доступна в настройках Android для приложения. |
| Стили | Настройка «Оформление»: **Чёрный** (текущий), **Аврора**, **Неон**, **Закат**, **Графит**. |

## Календарь (вкладка)

- Верх как на главной (логотип «А», Aura, поиск), крупный заголовок «Календарь».
- Стеклянная карточка: «‹ Ноябрь 2026 ›», дни недели с понедельника, сетка 6×7. Дни соседних месяцев затемнены.
- Кружки дней: зелёный — смена, красный — выходной, серый — без графика. **Сегодня** — циановое кольцо. **Выбранный день** — белое кольцо. Точка под числом — на этот день есть заметки.
- Нажатие — выбрать день (список его заметок ниже). Долгое нажатие — исключение смена/выходной (с вибрацией).
- Кнопка настройки графика в шапке карточки → нижняя панель: шаблон, N/M для своего, дата начала, «Сбросить график».
- Кнопка «+» с подписью «Заметка смены» справа внизу.

## Стили оформления

Фон рисуется под всеми экранами, стекло остаётся полупрозрачным поверх него.

- **Чёрный** — #121212, как сейчас.
- **Аврора** — тёмно-синий с мягкими сине-фиолетовыми и бирюзовыми пятнами света.
- **Неон** — почти чёрный, циановая и пурпурная подсветка по краям, яркие контуры карточек.
- **Закат** — глубокий фиолетовый, переходящий в тёплое пурпурно-оранжевое свечение внизу.
- **Графит** — тёмно-серый градиент с холодным бликом сверху.

## Технические решения

- **База данных: версия 1 → 2** (Room AutoMigration + тест миграции; удаления данных нет):
  - `notes.noteDate` — день заметки (число дней от 01.01.1970, может быть пустым), с индексом;
  - новая таблица `day_overrides(epochDay, isWorkDay)` — исключения графика.
- **Шаблон графика** хранится в настройках (DataStore), исключения — в базе.
- **Экспорт: формат 2** — добавлены дата заметки и исключения графика. Файлы формата 1 по-прежнему импортируются.
- **Даты:** java.time через «desugaring» (поддержка Android 7 сохраняется).
- **Язык:** системный механизм выбора языка приложения (Android 13+; на Pixel 8a работает). Английский перевод всех строк — `values-en`.
- **Версия:** `versionCode 2`, `versionName "1.1"`. Обновление встаёт поверх 1.0, заметки сохраняются.

## Этапы

1. База v2: дата заметки, исключения, миграция, тесты; убрать избранное из сортировки.
2. Логика графика (шаблоны, исключения) + тесты; настройки графика в DataStore.
3. Вкладка «Календарь» вместо «Избранного»; кнопка «Дата» в редакторе; дата на карточке.
4. Стили оформления.
5. Язык + английский перевод.
6. Экспорт формата 2, проверка на эмуляторе, release, установка на телефон.
