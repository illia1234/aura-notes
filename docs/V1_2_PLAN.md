# Aura v1.2 — учёт рабочих смен

22 нояб. 2026 г. По запросу пользователя и его ответам. Заменяет календарную часть `V1_1_PLAN.md` (зелёный/красный график и исключения).

## Как это работает

- Календарь по умолчанию **весь серый**.
- **Нажатие** на день — «я работал»: день **красный**, смена записывается с обычным временем **7:30–21:30**. Повторное нажатие убирает смену.
- **Долгое нажатие** — панель смены: время начала и конца (смена может переходить через полночь), часы считаются сами; «Сохранить» / «Убрать смену».
- Под календарём — **итог месяца**: смен · часов · евро.
- **Подсказка будущих смен**: по циклу пользователя будущие дни, где по графику смена, обведены тонким красным кольцом. В учёт и заметку попадают только отмеченные (красные) дни. Прогноз начинается после последней внесённой смены — так подмены, внесённые заранее, не перебиваются циклом.
- Цикл пользователя (найден по его спискам): **14 дней — 2 работы, 3 выходных, 2 работы, 2 выходных, 3 работы, 2 выходных**, начало цикла 2 декабря 2026. Есть в настройке графика как шаблон «2-3-2-2-3-2».

## Заметка «Mondieu»

- Одна заметка с меткой **#work**, приложение само создаёт и **перезаписывает** её при каждом изменении смен. Ручные правки в ней будут затёрты (в конце заметки об этом написано).
- Внутри — месяцы по порядку: день, время с–по, часы; под каждым месяцем итог «дней · часов · €».
- Ставка **7 €/ч** и обычная смена меняются в Настройках → «Работа».
